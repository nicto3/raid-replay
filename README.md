# Raid Replay (SPT 4.1.x, клиентский BepInEx-мод)

Запись рейдов и просмотр **от первого лица прямо в игре** (без вебсокетов и сайта). Работает с Fika (запись любых рейдов,
воспроизведение — соло). Всё настраивается в **F12 → вкладки «Raid Replay …»**, в главное меню ничего не добавляется.

## Статус — читать обязательно
| Часть | Состояние |
|---|---|
| Формат файла, запись, чтение, интерполяция, хранение «последние N», пины, математика миникарты | **Собрано и проверено тестами** (`tests/`, 40 проверок) |
| Игровой слой (`src/RaidReplay.Plugin`) | **Собран против локальных DLL EFT 0.16.9.** В самой игре ещё не запускался, поведение в рейде не проверено |

Весь код, который трогает классы Tarkov, собран в **одном файле — `EftBridge.cs`** (плюс `ShotPatch` в `RaidRecorder.cs`).
Если после обновления игры что-то не компилируется/не работает — чинится там.

## Сборка и установка
```
dotnet build src/RaidReplay.Plugin -c Release -p:EftDir="D:\EscapeFromTarkov\EscapeFromTarkov"
```
`EftDir` — папка SPT 4.1. DLL сам копируется в `BepInEx\plugins\RaidReplay\`. Нужен интернет для NuGet (BepInEx.Core, UnityEngine.Modules).
Тесты ядра: `dotnet run --project tests/RaidReplay.Core.Tests -c Release`.

## Как пользоваться
1. Играйте как обычно — каждый рейд пишется в `BepInEx/RaidReplay/replays/*.rrpl` (рейды короче 30 с отбрасываются).
2. F12 → **«0. Raid Replay - Replays»** → **Play** у нужной записи.
3. Зайдите в **соло-рейд на той же карте**. Мод сам заберёт камеру, расставит кукол и запустит запись.
4. Клавиши (меняются в F12): `Space` пауза · `← →` перемотка 10 с (Shift — 60 с) · `, .` скорость · `C` смотреть за другим ·
   `V` свободная камера (WASD, Q/E, колесо — скорость, Shift — быстрее) · `B` назад к оператору · `M` миникарта · `Home` скрыть HUD ·
   `End` выйти · удерживать `Alt` — курсор, клик по таймлайну = перемотка. Красные риски на таймлайне — убийства.

## Настройки (F12)
* **Recording**: вкл/выкл, **хранить последние N** (по умолчанию 5, до 500), частота записи остальных (15 Гц) и вашего вида (60 Гц), мин. длина рейда, папка.
  Закреплённые (**Pin**) реплеи не удаляются и не считаются в N.
* **Playback**: разрешить смотреть за другими / свободную камеру, имена над головами, трассеры выстрелов, таймлайн.
* **Minimap**: встроенная, без Raid Review и картинок карт. `Radar` (точки на тёмной панели) или `TopDownCamera` (живой вид сверху, экспериментально).
* **Operator badge**: плашка в стиле Таркова — портрет головы + ник + уровень + сторона.

## Вес
Замер на симуляции 25-минутного рейда, 25 сущностей (15 Гц, ваш вид 60 Гц): **3.1 МБ (~127 КБ/мин)**, загрузка 0.25 с.
Пять рейдов — порядка 15 МБ. Пишется кусками по 5 с в фоновом потоке; при вылете игры теряются только последние секунды.

## Что записывается / чего нет (v0.1)
Есть: позиция, направление взгляда, стойка (присед/лёжа), бег, прицеливание, наклон, жив/мёртв, FOV и **реальная камера оператора**
(покачивание, ADS, крен), выстрелы, убийства.
Нет: лут, двери, гранаты, дождь/время суток, точные анимации (куклы — капсулы с головой и «стволом»), модели с экипировкой,
оптика прицелов, звук. «1 в 1» сейчас = траектории и взгляды, а не пиксель-в-пиксель картинка.

## Известные ограничения
* Боты в рейде для просмотра **отключаются** (`SetActive(false)`, повторяется раз в секунду) — это грубо. Чище: рейд без ботов на стороне сервера.
* Воспроизведение отказывается стартовать, если в рейде есть другие живые игроки (Fika). Запись при этом работает всегда.
* Портрет лица рендерится с головы куклы; с настоящими моделями он станет настоящим лицом (формат файла уже резервирует `Blob` под профиль).
* Вкладка в **нативных** настройках EFT не делалась: F12 надёжнее переживает обновления.

## Дальше
1. Собрать, сообщить ошибки компиляции (правятся в `EftBridge.cs`).
2. Проверить рейд: запись → Play → сверить направление взгляда у ботов (знак pitch калибруется автоматически по вашей камере).
3. Куклы-модели через снимок профиля (формат готов), гранаты/лут/двери, нативная вкладка настроек.

## Сборка через GitHub Actions

Workflow `.github/workflows/build.yml` собирает мод на GitHub-hosted Windows runner при push в `main` или вручную. Он берёт compile-only reference DLL из публичного репозитория SAIN 4.1.0 во временную папку runner, собирает `RaidReplay.dll` и прикрепляет его как artifact. DLL EFT не добавляются в этот репозиторий или сборочный artifact; локальная игра не изменяется.
