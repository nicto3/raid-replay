# Raid Replay v0.3 (SPT 4.1.x, клиентский BepInEx-мод)

Запись рейдов и просмотр **от первого лица прямо в игре**, без сайта и вебсокета. Запись работает с Fika, просмотр — в соло-рейде.

## Где всё находится
Всё про реплеи — в одном окне **Replay Center**:
* кнопка **REPLAYS** в нижней панели нативного экрана Settings игры (рядом с DEFAULT/SAVE/BACK);
* клавиша **F10** (меняется), в рейде и в меню;
* F12 показывает единственную кнопку «Open Replay Center» (остальные настройки из F12 скрыты специально).

Вкладки: **REPLAYS** (карточки: карта, дата, длительность, размер, ник оператора, Play / Pin / Delete, очередь) · **RECORDING** (сколько хранить — по умолчанию 5, частоты записи, оценка веса) ·
**PLAYBACK** · **MINIMAP** · **OPERATOR** (плашка с портретом и ником) · **HOTKEYS** (переназначение кликом) · **ABOUT** (что синхронизируется, статус).
Интерфейс масштабируется под любое разрешение (виртуальные 1080p), шрифт Bender берётся из игры, если загружен.

## Статус проверки — честно
| Часть | Проверено |
|---|---|
| Формат файла v2, запись/чтение, обрезанные файлы, интерполяция, «хранить N» + пины, таймлайн мира (двери/лампы), математика миникарты | **51 автотест**, всё проходит (`tests/`) |
| Игровой мод | **Собирается без ошибок** против локальных DLL EFT 0.16.9, BepInEx, Harmony и Unity |
| UI, HUD, куклы, камера и поведение в рейде | **В игре ещё не запускалось** — нужен практический запуск и проверка |

Публичная CI-сборка использует compile-reference файлы из Fika 2.4.3; DLL игры и BepInEx не включаются в исходники или релизный архив.

## Сборка
```
dotnet build src/RaidReplay.Plugin -c Release -p:EftDir="C:\SPT"
```
`EftDir` — папка SPT 4.1. DLL копируется в `BepInEx\plugins\RaidReplay\`. Тесты ядра: `dotnet run --project tests/RaidReplay.Core.Tests -c Release`.

## Что синхронизируется в реплее
* **Игроки и боты:** позиция, взгляд, присед/лёжа, бег, прицеливание, наклон, жив/мёртв; падение при смерти; вспышка выстрела и трассер.
  Тела — **стилизованные человечки с процедурной анимацией** (цикл ходьбы/бега по скорости, присед, наклон, оружие вскинуто при прицеливании).
* **Ваш вид:** реальная камера из записи (покачивание, ADS, FOV, крен).
* **Двери и контейнеры** (открыть/закрыть/запереть/отпереть), с анимацией при обычном просмотре; при перемотке состояние подстраивается к нужному моменту.
* **Лампы и свет** (включение/выключение электричества).
* Убийства — лента и красные риски на таймлайне.

## Загрузка и «обычный рейд» (новое в 0.3)
Что нашлось по исследованию: карта грузится в рамках всего конвейера старта рейда (`TarkovApplication.LoadMapAndData → LocalGameMatching → LocalGameCreate`), вместе с GameWorld,
игроком и лутом с сервера. Загрузить 3D-карту отдельно из меню без этого конвейера безопасно не получится. Зато можно убрать лишнее из самого рейда:
* **Quiet raid** (включено по умолчанию): если реплей в очереди, мод через тот же хук, что использует сам SPT, запускает рейд **без ботов, боссов, PMC-волн и без голода/жажды**.
  Рейд генерируется быстрее, убить камеру некому. Время загрузки пишется в лог и показано во вкладке ABOUT — сравни с обычным рейдом и скажи цифры.
* **SWITCH**: уже находясь в рейде на нужной карте, любой другой реплей этой карты включается мгновенно, без новой загрузки.
* **Exit key also extracts** (выключено по умолчанию): выход из реплея заканчивает рейд как «Survived», вещи сохраняются. Идёт в статистику и квесты как обычный выжитый рейд; в Fika недоступно.
* Для безопасности вещей всё равно лучше заходить пустым комплектом или скавом.

## Чего пока нет (и почему)
* **Настоящие модели с экипировкой и их «родные» анимации.** Для этого нужно создавать удалённых игроков так, как это делает Fika: её `ObservedPlayer` + движение + контроллеры занимают ~7000 строк внутреннего кода, который нельзя вслепую писать без запуска игры. Поэтому сейчас куклы стилизованные. Формат файла уже хранит место под профиль/экипировку.
* Лут на земле, гранаты и дым, разбитые окна, погода/время суток.
* Боты в рейде просмотра отключаются грубо (`SetActive(false)`), надёжнее — рейд без ботов на сервере.

## Как смотреть
1. Играйте как обычно — запись идёт сама, файл появляется после выхода из рейда (`BepInEx/RaidReplay/replays`).
2. Replay Center → REPLAYS → **PLAY**.
3. Зайдите в **соло-рейд на той же карте** — мод заберёт камеру и запустит просмотр.
4. Клавиши: `Space` пауза · `← →` ±10 с (Shift — 60 с) · `, .` скорость · `C` смотреть за другим · `V` свободная камера · `B` назад к оператору · `M` миникарта · `Home` скрыть HUD · `End` выход · `Alt` — курсор для клика по таймлайну.

## Вес
Измерено на симуляции 25-минутного рейда с 25 сущностями: **3.1 МБ** (~127 КБ/мин). Данные дверей/ламп — единицы килобайт.

## GitHub Actions и релизы
При push в `main` workflow собирает DLL на временном Windows runner и публикует её как artifact. Для компиляции он получает публичные reference DLL из Fika 2.4.3 и Unity modules; игровые DLL не входят в исходники и artifact. Релизы содержат готовый `RaidReplay.dll` внутри папки `BepInEx/plugins/RaidReplay/`.
